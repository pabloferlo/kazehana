Aquí puedes poner tus propias imágenes de retrato (PNG).
Nombre: <id>_<estado>.png  (por ejemplo n_rival_alegre.png, player_neutral.png)
Estados: neutral, alegre, timido, enfadado, triste, coqueto, sorprendido, serio, burlon, avergonzado, enamorado, nervioso, sereno
Para activarlas: en js/portraits.js pon Port.custom.enabled = true y añade a cada personaje el campo img (ver README.md).
