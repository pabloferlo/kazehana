⚠️ El juego no puede arrancar así

Has abierto index.html con doble clic. Los navegadores bloquean los módulos JavaScript y la carga de datos desde file://.

Solución fácil: ejecuta jugar.bat (Windows) o jugar.command / jugar.sh (Mac/Linux), que abren el juego en tu navegador.

O manualmente, en esta carpeta: python3 -m http.server 8000 y abre http://localhost:8000. También funciona subiéndolo a GitHub Pages.
