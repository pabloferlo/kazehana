# Imágenes de ultimates

Coloca aquí PNG (recomendado 1600×900, fondo transparente o negro, personaje/ilustración centrada).

El juego busca primero `<id_de_la_técnica>.png` y, si no existe, `<id_del_personaje>.png`. Si no hay ninguna, muestra solo el texto como antes.

## Técnicas definitivas por clase (protagonista)
- Guerrero: `furia_del_titan.png` (Furia del Titán)
- Mago de Fuego: `supernova_carmesi.png` (Supernova Carmesí)
- Mago de Hielo: `era_glacial.png` (Era Glacial)
- Mago del Rayo: `tormenta_celestial.png` (Tormenta Celestial)
- Mago Arcano: `eclipse_arcano.png` (Eclipse Arcano)
- Espadachín Mágico: `mil_lunas.png` (Mil Lunas)
- Monje Rúnico: `dragon_interior.png` (Dragón Interior)
- Duelista Arcano: `lluvia_de_estrellas.png` (Lluvia de Estrellas)

## Yukine
- `aullido_lunar.png` (transformación) o `yukine.png` (cualquier ultimate suya)

## Enemigos (ataque especial del jefe)
- `<id_del_enemigo>.png`, p. ej. `kurogane.png`, `reiga.png`, `yamikage.png`, `yamikage_alba.png`
## Ataque de Unión (protagonista + Yukine)
Un PNG por clase: `unison_guerrero.png`, `unison_mago_fuego.png`, `unison_mago_hielo.png`, `unison_mago_rayo.png`, `unison_mago_arcano.png`, `unison_espadachin_magico.png`, `unison_monje_runico.png`, `unison_pistolero_arcano.png`. Si falta, usa `unison.png`.
