# Fondos de imagen

Coloca aquí imágenes **.jpg, .png o .webp** (recomendado 1920×1080, horizontal). El nombre del archivo es el **id** de la tabla (por ejemplo `bosque_niebla.jpg`). Todos son opcionales: si falta uno, se ve el degradado de color de siempre. El juego oscurece un poco la imagen para que se lea el texto.
